# OpenShift Pipelines Final Project

## Project Name

OpenShift Pipelines Final Project

## Description

This project demonstrates a complete CI/CD pipeline using GitHub Actions,
Tekton and OpenShift Pipelines.

The project includes continuous integration with linting and unit testing,
followed by continuous deployment using OpenShift Pipelines.

## Technologies

- Python
- GitHub
- GitHub Actions
- Tekton
- OpenShift Pipelines
- Docker / Buildah
